
## Parallel Life Simulator

A fun experiment that lets users explore alternate versions of their future.

The idea came from a simple question:

"What if I had chosen a completely different path?"

This project simulates multiple timelines based on user decisions and visualizes how small choices can lead to very different outcomes.

## Features

● Explore multiple life and career paths
● Compare different future versions of yourself
● Track how small decisions change outcomes
● Visual journey maps
● Milestone collection system
● Dark mode
● Downloadable PDF reports

## Built With

● CSS
● JavaScript
